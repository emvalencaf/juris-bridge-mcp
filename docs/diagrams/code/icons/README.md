# AWS Architecture Icons

The four SVG files in this folder are the official **AWS Architecture Icons**,
copied unmodified from the Icon package and used only by
[04-aws-deployment](../04-aws-deployment.html).

| File | Service |
|---|---|
| `Arch_Amazon-Elastic-Container-Registry_64.svg` | Amazon Elastic Container Registry |
| `Arch_AWS-Lambda_64.svg` | AWS Lambda |
| `Arch_Amazon-CloudWatch_64.svg` | Amazon CloudWatch |
| `Arch_AWS-Identity-and-Access-Management_64.svg` | AWS Identity and Access Management |

## Source

- Page: <https://aws.amazon.com/architecture/icons/>
- Package: `Icon-package_07312026.zip` (release of 31 July 2026), file group
  `Architecture-Service-Icons`, size `64`, SVG.
- Downloaded 2026-10-18. Only these four icons were extracted; the rest of the
  package is not redistributed here.
